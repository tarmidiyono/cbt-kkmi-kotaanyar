# CBT KKMI KOTAANYAR — Frontend

Frontend statis (HTML/CSS/JS vanilla) untuk aplikasi Ujian CBT tingkat kecamatan.
Backend: Google Apps Script (REST API JSON) + Google Sheets — **tidak termasuk repo ini**.

1. Edit `js/config.js` → isi `GAS_URL` dengan URL Web App `/exec`.
2. Push ke GitHub → Settings → Pages → branch `main` / root.

Panduan lengkap: `PANDUAN-INSTALASI.md`.
